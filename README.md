# 🛍️ NammaMart

NammaMart is a MERN stack based multi-vendor local e-commerce web application. It allows customers to browse products, manage their cart and wishlist, place orders, and allows sellers to manage their products and orders.

## 🚀 Features

### Customer
- User Signup & Login
- Browse products
- Search products
- Product categories
- Add to Cart
- Wishlist
- Place Orders
- View My Orders
- Cancel Orders
- Manage Profile

### Seller
- Seller Login
- Add Products
- Edit Products
- Delete Products
- View Seller Products
- Manage Customer Orders
- Update Order Status

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Git & GitHub
